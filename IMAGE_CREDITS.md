# Image Credits — Vehicle Rental Project

All vehicle photos in this project are **hot-linked directly from Wikimedia Commons** (`upload.wikimedia.org`).
**No images were downloaded, re-hosted, cropped, or modified.** Every image was attached through the
admin UI (`POST /api/vehicles/{id}/images`) as the vehicle's primary image, one per vehicle.

- **Attached:** 2026-10-10 (Phase 12D-2)
- **Total images:** 12 (image IDs #85–#96), one primary image per vehicle
- **Selection:** candidates were chosen from Wikimedia Commons metadata, pre-inspected visually by the
  assistant, and individually confirmed by the project owner before attachment.

License obligations (attribution + share-alike where applicable) are satisfied by this file: each entry
below credits the author and links the license and the original Commons file page.
